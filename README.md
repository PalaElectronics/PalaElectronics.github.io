# Mijn Persoonlijke Website – BEHEER1A (Opdracht 22)

Dit project is gemaakt voor de module **BEHEER1A: Linux Client** (Opleiding Software Developer, Leerjaar 1 – Grafisch Lyceum Rotterdam).

## Over dit project
Voor Opdracht 22 heb ik in Visual Studio Code een persoonlijke welkomstpagina (`index.html`) met bijbehorende stylesheet (`css/style.css`) opgezet. Omdat de school-FTP-server tijdens het maken van deze opdracht niet bereikbaar was, wordt deze website gehost via **GitHub Pages**.

## Mappenstructuur
```text
├── index.html       # De hoofdpagina van de website
├── css/
│   └── style.css    # Opmaak en styling van de pagina
├── README.md        # Uitleg en documentatie van de repository
└── .nojekyll        # Zorgt ervoor dat GitHub Pages bestanden direct zonder Jekyll-verwerking serveert
```

## Live bekijken
Zodra GitHub Pages is ingeschakeld onder **Settings > Pages**, is de website live te bekijken via:
`https://<jouw-github-gebruikersnaam>.github.io/<repository-naam>/`
